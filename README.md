## Kaori 🌷

Landing Page de Vendas de Flores

## Descrição

Projeto de uma aplicação web full stack para divulgação e venda de buquês online.

## Objetivo

Desenvolver uma landing page comercial que permita apresentar produtos, captar clientes, realizar verificação de e-mail, efetuar pagamento online e registrar pedidos.

## Tecnologias

- Next.js
- Git e GitHub
- Docker
- PostgreSQL
- Mercado Pago
- Figma
